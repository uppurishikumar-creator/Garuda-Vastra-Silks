# Garuda Vastra Silks — Website Concept

A redesign concept for Garuda Vastra Silks by **Driksha** (https://driksha-website-mt52.vercel.app/).

Features: Virtual Saree Try-On, Saree Finder, wishlist, WhatsApp enquiry, Telugu / English, store locator with live open status, bridal & video-call appointments, mobile app-style navigation.

Catalogue items and prices are samples for this preview.
